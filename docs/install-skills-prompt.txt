Install the Triad, Triad Easy, and Triad Ultra review skills globally for Codex, Claude Code,
and Kimi Code.
Use the official repository: https://github.com/nocell/triad-harness.

If `triad` is not installed or `triad install-skill --help` lacks --ultra-mode,
install/update it from that repository with
`cargo install --git https://github.com/nocell/triad-harness --locked`.
If Cargo is unavailable, ask me which installation method to use.

Before overwriting any existing Triad skill files, preserve a backup of them.
Run `triad install-skill --host all --yes`.
Then run `triad install-skill --host all --easy-mode --yes`.
Then run `triad install-skill --host all --ultra-mode --yes`.
Verify that SKILL.md exists and has matching content across hosts for each skill:
- ~/.codex/skills/triad/
- ~/.claude/skills/triad/
- ~/.kimi-code/skills/triad/
- ~/.codex/skills/triad-easy/
- ~/.claude/skills/triad-easy/
- ~/.kimi-code/skills/triad-easy/
- ~/.codex/skills/triad-ultra/
- ~/.claude/skills/triad-ultra/
- ~/.kimi-code/skills/triad-ultra/
Also verify agents/openai.yaml exists under all three Codex skill directories.
The skills intentionally differ: Triad Easy uses --easy-mode (Opus 5.5 and
GPT-6.1 Sol); Triad Ultra uses --ultra-mode (Opus 5.5 Ultracode and GPT-6 Astra
with ultra reasoning plus ordinary Fast, not Ultrafast); regular Triad keeps
its normal model preset.
Report the installed paths and how to invoke the skill.

Do not install or update vendor agent CLIs, start logins, change credentials
or account settings, or run a review or fix as part of this setup.
